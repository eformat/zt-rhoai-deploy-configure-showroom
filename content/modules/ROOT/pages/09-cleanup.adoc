= Cleanup
:navtitle: Cleanup
:toc: macro
:toclevels: 1
:icons: font

Remove the resources created during the workshop. Run the steps in reverse order of the modules so
dependencies are torn down cleanly.

== Remove workload resources

[source,bash,role="execute",subs="attributes"]
----
# Module 6 — llm-d + WVA
oc delete -k manifests/06-llmd/autoscaling -n {project_name} --ignore-not-found
oc delete -k manifests/06-llmd/service -n {project_name} --ignore-not-found

# Module 5 — MaaS
oc delete -k manifests/05-maas/subscription -n {project_name} --ignore-not-found

# Module 4 — vLLM model
oc delete -k manifests/04-vllm/qwen25-05b -n {project_name} --ignore-not-found
----

== Remove the project

[source,bash,role="execute",subs="attributes"]
----
oc delete project {project_name} --ignore-not-found
----

== Remove platform add-ons (optional)

[WARNING]
====
Only remove the operators and {rhoai-short} itself if this cluster was dedicated to the workshop.
Deleting the `DataScienceCluster` removes all {rhoai-short} components.
====

[source,bash,role="execute"]
----
# MaaS database and gateway
oc delete -k manifests/05-maas/gateway --ignore-not-found
oc delete -k manifests/05-maas/postgres -n redhat-ods-applications --ignore-not-found

# RHOAI (dedicated clusters only)
oc delete -k manifests/01-install/dsc --ignore-not-found
oc delete -k manifests/01-install/operator --ignore-not-found
----

== Verify

[source,bash,role="execute",subs="attributes"]
----
oc get project {project_name} 2>/dev/null || echo "project removed"
----

* The workshop project is gone and no workshop workloads remain.

Thank you for completing the *{lab_name}* workshop!
