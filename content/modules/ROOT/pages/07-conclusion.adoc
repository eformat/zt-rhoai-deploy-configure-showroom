= Conclusion
:navtitle: Conclusion
:icons: font

Congratulations — you have deployed, configured, served, governed, scaled, and observed {rhoai}
{rhoai_version} end-to-end on a CPU-only cluster.

== What you accomplished

* *Module 1 — Install (Connected)*: Installed the {rhoai-short} Operator and reached a `Ready`
  `DataScienceCluster`.
* *Module 2 — Install (Disconnected)*: Mirrored {rhoai-short} with oc-mirror v2 and installed from a
  local `CatalogSource`, plus the Quay proxy pull-through cache alternative.
* *Module 3 — Model-Serving Platform*: Enabled KServe single-model serving and made the pre-installed
  vLLM CPU runtime available in your project.
* *Module 4 — Serving with vLLM*: Served `{cpu_model}` and queried it via the OpenAI-compatible API.
* *Module 5 — MaaS Governance* (Tech Preview): Governed access with subscriptions, API keys, and
  token rate limiting.
* *Module 6 — Scaling with llm-d + WVA* (Tech Preview): Scaled distributed inference on
  inference-specific signals.
* *Module 7 — Observability*: Viewed vLLM engine metrics and MaaS token-usage telemetry.

== Where to go next

* Enable GPUs and swap in larger validated models (Granite, Llama) — the runtime and hardware-profile
  hooks are already in place.
* Harden the disconnected pipeline for your registry and air-gap policy.
* Promote the Technology Preview modules once the features reach GA.
